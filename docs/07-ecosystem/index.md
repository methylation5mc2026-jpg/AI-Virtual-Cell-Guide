# 组织、平台与挑战

## 开放倡议

- [Arc Virtual Cell Initiative](https://arcinstitute.org/virtual-cell-initiative)：建设扰动图谱、STATE 模型和年度 Virtual Cell Challenge。
- [CZI Virtual Cells Platform](https://virtualcellmodels.cziscience.com/)：集中提供单细胞与细胞成像模型、数据集、教程和模型卡。
- [Human Cell Atlas](https://www.humancellatlas.org/)：绘制人类细胞参考图谱。
- [HuBMAP](https://hubmapconsortium.org/)：构建人体组织空间与多组学图谱。

## 数据与分析生态

- [CELLxGENE](https://cellxgene.cziscience.com/)提供可查询的标准化单细胞数据；
- [scverse](https://scverse.org/)维护 AnnData、Scanpy、scVI-tools、PertPy 等 Python 工具；
- [Bioconductor](https://www.bioconductor.org/)和 Seurat 构成重要 R 生态；
- [scPerturb](https://www.sanderlab.org/scPerturb/)提供统一的单细胞扰动数据资源。

## 挑战与基准

Arc Virtual Cell Challenge 以新的 Perturb-seq 数据评测未见扰动预测。Open Problems 通过公开竞赛推动多组学整合和药物扰动预测。此类挑战的最大价值是公开拆分、指标和失败模式，但排行榜不等于生物学验证。

## 如何跟踪进展

按季度而不是每天追逐新模型：

1. 先看数据、任务和评测是否真的变化；
2. 区分同行评审、预印本和产品发布；
3. 检查代码、权重、数据和许可证；
4. 优先阅读复现、消融和负面结果；
5. 把“新名字”映射回本指南的稳定任务分类。

## 社区收录标准

组织和公司条目只记录公开倡议、数据、模型和研究输出，不做投资或商业排名。存在利益冲突时，贡献者必须披露。

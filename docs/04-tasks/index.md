# 任务版图

## 第一层：表示与测量

- 细胞类型注释、聚类和检索；
- 批次整合与参考图谱映射；
- 缺失模态补全和跨模态对齐；
- 基因、细胞与组织 embedding；
- 图像分割、定位和形态表征。

这些任务建立“状态空间”，但不能单独证明模型会模拟状态变化。

## 第二层：状态转换

- 基因或药物扰动响应预测；
- 剂量—反应和时间动态；
- 细胞分化、疾病进展和状态逆转；
- 组合扰动和协同效应；
- 从一种生物背景迁移到另一种背景。

这是当前 AIVC 最可操作的核心。

## 第三层：机制与虚拟实验

- 基因调控网络和通路推断；
- 靶点、药物和组合优先级；
- 假设生成与反事实查询；
- 不确定性估计和失败检测；
- 主动选择下一批最有信息量的实验。

## 第四层：闭环系统

模型提出实验 → 自动或人工执行 → 数据质控 → 更新模型 → 重新选择实验。评价对象从单次预测准确率变为发现效率、实验成本和可重复性。

## 任务描述模板

```text
给定：
  初始细胞背景、可观测状态、干预、剂量、时间
预测：
  目标模态中的状态或分布
泛化：
  明确未见扰动、细胞、供体、组织或物种
验证：
  统计基线 + 独立数据 + 真实实验
用途：
  排序、筛选、机制解释或实验决策
```

如果一个项目不能填完这份模板，它很可能还只是模型演示，而不是定义完整的 AIVC 任务。

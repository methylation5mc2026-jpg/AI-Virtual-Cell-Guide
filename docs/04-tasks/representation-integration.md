# 表征、注释与数据整合

“学习细胞表示”本身不是完整任务。必须说明表示服务于什么下游目标，以及哪些变异需要保留、哪些技术因素需要去除。

## 任务拆解

- 降维：用较少维度保留主要结构。
- 批次整合：减少技术来源，同时保留生物差异。
- 细胞类型注释：预测离散标签和置信度。
- 状态检索：在参考图谱中找到相似细胞或群体。
- 标签迁移：从参考数据把注释投射到查询数据。
- 跨模态对齐：连接 RNA、ATAC、蛋白、空间或成像表示。

## “混合得更好”可能是坏事

如果疾病状态、扰动或组织差异与批次相关，过度校正会删除真实信号。整合评测需要同时衡量批次混合和生物保留，并检查稀有群体。

## 未知类型

封闭集合分类器总会给出已有标签。真实查询数据可能含未知细胞类型、双细胞或低质量群体，因此需要拒识、距离阈值、校准和人工复核入口。

## 参考图谱污染

当查询数据已参与预训练或参考图谱构建，结果不能当作真正独立映射。应记录语料和图谱版本，对来源重叠做检查。

## 推荐输出

- 细胞级 embedding 与版本；
- 标签概率而不只是最终标签；
- 未知/低置信标记；
- 参考邻居及来源；
- 批次、生物标签和稀有群体指标；
- 失败样本和人工复核记录。

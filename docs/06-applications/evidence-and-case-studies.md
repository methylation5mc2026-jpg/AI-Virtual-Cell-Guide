# 应用案例与证据卡

应用章节只回答“在哪个明确场景、基于什么证据、能支持多强的主张”。所有医学与药物案例均为研究资料，不构成诊断或治疗建议。

## 靶点优先级：E1–E3

模型可根据疾病状态逆转、网络位置、跨背景稳定性或形态相似性排序靶点。最低比较包括已知靶点、差异表达、通路规则和随机排序。只有在模型先给出候选、随后用独立干预验证时，才能达到 E3。

## 药物反应：E1–E3

CPA、CellOT、Cell Painting 和 RxRx 等资源支持剂量、背景与形态响应建模。必须区分：

- 已见药物的新细胞背景；
- 新药物但已见靶点；
- 新结构和新靶点；
- 组合与单药相加基线。

疾病逆转分数只是计算代理，不能直接解释为治疗效果。

## 疾病状态建模：E0–E2

患者和健康样本通常伴随供体、组织、治疗史和平台混杂。模型可以检索相似状态或提出逆转候选，但因果结论需要额外设计。外部队列、跨中心和匹配组织验证是 E2 的最低要求。

## 细胞命运与工程：E1–E3

轨迹模型可预测终末状态或重编程路径。前瞻验证需要真实时间、谱系或功能读出；只在同一数据上恢复标记基因属于 E1。

## 主动学习与自动化实验：E0–E3

完整闭环要记录每轮候选、实验预算、阴性结果和模型更新。离线回放属于 E1，基于历史已知结果的“发现”不算前瞻。真实多轮实验并优于固定或随机策略，才可进入 E3。

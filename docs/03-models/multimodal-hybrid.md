# 多模态、多尺度与机理混合模型

真正的虚拟细胞不能只依赖转录组。细胞功能还涉及蛋白定位、信号网络、代谢、形态、邻域与组织环境。多模态模型尝试建立共同表示，混合模型则把数据驱动模块与已知机制连接。

## 三种整合层级

1. **早期融合**：把多模态特征直接输入同一模型；简单但容易受尺度和缺失模态影响。
2. **潜空间融合**：每个模态有专属编码器，再对齐或共享部分潜变量。
3. **决策融合**：各模态独立建模，最后组合预测与不确定性。

没有一种融合方式普遍最好。选择取决于模态是否配对、缺失模式、样本量和任务。

## 从细胞到组织

空间模型还要表达细胞与邻域、细胞与组织结构之间的关系。常见表示包括邻域图、连续坐标、图像 patch 和多尺度网格。必须检验模型提升来自真实邻域信息，还是组织区域标签或切片捷径。

## 机理混合

可连接的模块包括：

- 基因调控或信号网络；
- ODE/SDE 状态方程；
- 代谢通量约束；
- 细胞力学与空间相互作用；
- 数据驱动的未知项或残差。

每个接口都应声明单位、状态变量、时间尺度和守恒条件。将知识图作为神经网络输入不等于模型遵守该机制。

## 验证策略

- 单模态消融：新增模态是否带来跨批次稳定增益？
- 模态缺失：部署时缺少一个模态会怎样？
- 错配对照：打乱空间邻域或跨模态配对后性能应下降。
- 机制消融：移除约束后是否产生物理或生物不可行结果？
- 外部表型：联合表示能否预测未参与训练的蛋白、形态或功能读出？

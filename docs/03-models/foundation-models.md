# 单细胞基础模型

单细胞基础模型通常在大规模表达图谱上预训练，再迁移到注释、整合、网络或扰动任务。模型规模只是其中一个维度；预训练数据、表示方式和迁移协议更直接决定它能学到什么。

## 五个设计问题

### 1. 一个 token 是什么？

常见方案包括按表达量排序的基因序列、基因 token＋离散表达 bin、连续表达值和集合表示。排序会弱化绝对丰度，分箱会丢失细粒度数值，截断会系统性排除低表达基因。

### 2. 基因词表如何对齐？

不同物种、基因版本、别名和同源关系必须显式处理。未知基因不能悄悄映射到随机向量；模型应记录丢失比例和回退策略。

### 3. 预训练目标是什么？

掩码重建、排序恢复、对比学习和生成式目标优化的是不同能力。重建已见表达分布不等价于预测干预后的状态。

### 4. 语料中有什么？

大型图谱同时编码组织、疾病、平台和实验室信息。下游测试集若已出现在预训练语料中，零样本结果可能是记忆、相似检索或平台捷径。

### 5. 如何迁移？

冻结 embedding、线性探针、参数高效微调和全量微调的计算成本与过拟合风险不同。比较时应加入随机初始化、基因身份和传统特征基线。

## 评测清单

- 公布预训练数据清单或可查询的语料指纹；
- 测试集按来源、供体和时间检查重叠；
- 同时评估低样本、跨组织、跨物种和新平台；
- 报告冻结与微调两种设置；
- 比较同规模非预训练模型和简单基因嵌入；
- 测试基因顺序、表达缩放和缺失基因敏感性。

## 不要把 attention 当机制

注意力、梯度归因或 embedding 邻域可以提出候选关系，但它们受输入表示、模型参数化和训练目标影响。调控机制仍需要扰动、时间信息和独立实验。

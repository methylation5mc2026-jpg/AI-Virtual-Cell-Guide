# 统计基线与概率模型

“基线”不是为了容易被击败。它用最少假设回答：数据中究竟有多少信号？复杂模型增加的能力是否真的来自结构学习，而不是数据泄漏、调参预算或指标权重？

## 四级基线阶梯

1. **控制均值**：所有条件都预测匹配控制组的平均状态。
2. **平均扰动效应**：训练扰动的平均变化加到控制状态。
3. **分组线性模型**：用处理、批次、重复和已知协变量解释 pseudobulk。
4. **相似性/最近邻**：根据靶点、通路、化学或训练响应寻找近邻。

如果模型连控制均值都不能稳定击败，问题通常不是“需要更大模型”，而是效应弱、拆分困难或目标定义不合适。

## 为什么 pseudobulk 强

按 `(condition, cell_type, replicate)` 聚合能：

- 与独立实验单位一致；
- 降低细胞采样噪声；
- 使用成熟的计数统计工具；
- 明确区分重复内异质性和重复间变异。

它不适合替代分布建模，但应作为平均效应预测的首要参照。

## 概率模型的价值

scVI、totalVI 等模型显式描述计数、批次和背景噪声，可以：

- 估计潜在细胞状态；
- 生成后验预测和不确定性；
- 处理缺失模态或蛋白背景；
- 将测量模型与下游任务连接。

但模型似然正确不代表潜变量具有因果或机制解释。必须通过后验检查、独立批次和下游任务验证。

## 公平比较

所有模型应共享：

- 相同的训练、验证和测试实验单位；
- 相同的基因集合和归一化信息；
- 不使用测试集的早停、缩放或基因选择；
- 明确的超参数预算；
- 相同的失败处理和随机种子报告。

Arc 2025 的复盘再次说明，简单统计与混合方案可能比纯深度模型更可靠，因此基线必须出现在主结果表而不是附录。

# 动力学、最优传输、扩散与流匹配

静态生成模型学习“像真实细胞的样本”，动力学模型还需要回答“状态如何随时间或干预改变”。这通常是不可识别问题：多个动力学过程可能产生相同的快照分布。

## 三种视角

### 向量场

RNA velocity、Dynamo 等方法从局部信息估计状态空间中的方向。它们适合短时间趋势，但依赖剪接或代谢动力学、邻域和状态空间。

### 最优传输

最优传输寻找把一个群体分布变成另一个分布的低代价耦合。Waddington-OT 连接时间点，CellOT 学习扰动映射。代价函数和正则化定义了“最小改变”，并非由数据唯一决定。

### 扩散与流匹配

扩散模型通过逐步去噪学习分布；流匹配直接学习连续向量场。条件变量可以是时间、扰动或细胞背景。它们生成灵活，但需要特别防止记忆训练细胞和条件捷径。

## 需要的约束

更可信的动力学来自多源约束：

- 真实时间点和时间间隔；
- 条形码谱系或成像追踪；
- 增殖、死亡和采样比例；
- 分子网络或守恒关系；
- 独立干预后的方向验证。

## 评测

除终点表达误差外，还应检查：

- 中间时间点预测；
- 轨迹方向和终末状态；
- 群体质量是否守恒或正确增减；
- 谱系/追踪真值的一致性；
- 新时间、新扰动和新背景的外推；
- 路径不确定性和多解性。

一个模型能把终点分布拟合得很好，并不意味着它恢复了真实路径。

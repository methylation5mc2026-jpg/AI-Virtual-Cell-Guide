# 从基线到基础模型

## 推荐基线阶梯

1. **控制均值**：所有扰动都预测为控制状态；
2. **全局平均效应**：使用训练扰动的平均表达变化；
3. **近邻或通路基线**：复用最相似训练扰动的效应；
4. **线性/岭回归**：从干预特征预测表达变化；
5. **小型 MLP**：检验非线性是否带来稳定收益；
6. **任务专用模型**：如 GEARS、CPA；
7. **基础模型表征或微调**。

每上升一级，都应回答新增复杂度究竟利用了什么信息。

## 为什么控制均值会很强

大部分基因在一个扰动下变化很小，直接预测控制状态可以获得很低的全转录组平均误差。MAE 或 MSE 因而可能奖励“什么都不发生”的模型。

相反，只关注差异基因的指标可能忽略大量非响应基因或被阈值影响。需要同时报告全局误差、方向、DE 恢复和扰动可区分性。

## 基础模型的公平比较

- 预训练数据是否包含测试数据或相同供体？
- 与随机初始化、冻结表征、线性探针分别比较了吗？
- 训练预算和下游数据量是否一致？
- 是否和同参数量模型、PCA、HVG＋MLP 比较？
- 提升是否在多个数据集和 OOD 背景复现？

## 何时值得使用基础模型

当任务需要跨数据集迁移、低样本适配、多任务共享或能利用序列/知识先验时，基础模型更可能有价值。若数据单一、标签充分且任务明确，小模型可能更稳定、便宜和易解释。

## 本项目实践

扰动响应教程严格按上述阶梯运行。轻量 MLP 使用确定性的固定基因嵌入演示模型接口，但不会把该教学嵌入宣称为生物学表征；真实项目应替换为经验证的蛋白、基因或通路表示。

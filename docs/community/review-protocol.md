# 试读与可用性验收

## 发布前角色化审读

本轮先以三类读者视角完成内部检查，结果不冒充外部反馈：

| 角色 | 核对重点 | 本轮修正 |
|---|---|---|
| AI 新人 | 术语门槛、路线是否可开始 | 增补 80+ 术语、先基线后深度模型 |
| 生信研究者 | AnnData、重复、QC、泄漏 | 契约 v2、控制细胞不相交、counts 来源审计 |
| 实验研究者 | 扰动单位、证据边界 | 增补实验设计、伪重复、湿实验验证章节 |

## 外部试读任务

试读者从首页出发，完成以下任务并记录点击数、卡点和错误：

1. 找到一个扰动预测模型的代码、数据与限制；
2. 解释为何随机按细胞拆分会泄漏；
3. 在无 GPU 环境运行 Notebook 01–04；
4. 区分本地 Top-DE overlap 与 Arc 官方指标；
5. 指出一个无法从当前证据推出的生物学结论。

建议反馈字段：背景、设备、任务完成情况、首个卡点、错误截图、最难术语、建议修订。
公开 Beta Issue 是本轮外部试读的唯一收集入口，所有结论按实际回复更新。

# 贡献与审校

欢迎提交资源、概念纠错、失效链接、Notebook 复现和实验语义反馈。完整流程见仓库根目录
[CONTRIBUTING.md](https://github.com/methylation5mc2026-jpg/AI-Virtual-Cell-Guide/blob/main/CONTRIBUTING.md)。

## 内容贡献

- 说明目标读者和应解决的概念断点；
- 关键结论使用一手来源；
- 区分事实、推断和建议；
- 医学案例标注研究性质和证据阶段；
- 不复制受限论文图、PDF 或第三方大段文字。

## 目录贡献

目录唯一数据源为 `catalog/*.yml`。新增条目必须提供官方来源、许可证、复现状态、计算需求、已知限制和实际核验日期，并通过 Schema v2 与统一词表校验。

## 复现贡献

提交环境、数据版本、拆分、随机种子、硬件、运行时间、指标与失败信息。不要上传受限生物数据、患者数据或大型模型权重。

## 审校角色

- AI 新人：检查前置概念和学习路径；
- 生信研究者：检查数据语义、统计和复现；
- 实验研究者：检查扰动、控制和验证是否合理；
- 维护者：检查来源、许可、格式和自动化。

外部试读反馈属于产品质量记录，不等同于论文同行评审。

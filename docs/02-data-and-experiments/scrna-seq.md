# scRNA-seq：从实验到表达矩阵

scRNA-seq 是当前 AIVC 最常见的数据模态，但它主要测量转录本的稀疏快照，不直接测量蛋白活性、代谢通量、细胞形态或未来命运。

## 协议决定数据语义

- 液滴式 3′/5′ 计数适合大规模细胞图谱，通常只观察转录本一端并使用 UMI。
- 全长协议覆盖转录本更完整，但通量较低。
- 单核 RNA 测序适合冻存组织，却与全细胞测量存在系统差异。
- Perturb-seq 额外读取 guide 或扰动身份，仍需处理多 guide、未编辑细胞和错配。

在合并数据前，至少记录物种、组织、供体、协议、化学版本、参考基因组、测序批次和处理时间。

## 最小 QC

QC 不是固定阈值，而是利用实验结构识别异常：

1. 每细胞总计数、检测基因数和线粒体比例；
2. 空液滴、低质量细胞和双细胞；
3. 不同批次、供体和条件的分布；
4. guide 质量、扰动多重性与未分配比例；
5. 过滤前后每个实验单位保留的细胞数。

如果过滤规则使用了处理后的响应变量，可能改变处理组组成并引入选择偏差。

## 归一化与高变基因

文库大小归一化与 log1p 便于探索，但不能保证不同细胞的绝对 RNA 含量可比。高变基因选择会改变模型看到的任务：只保留变异最大基因可能遗漏靶点附近的弱效应，也可能让评测偏向训练时选出的特征。

建议把原始计数、标准归一化矩阵和特定模型输入分层保存，并记录基因过滤、归一化目标和版本。

## AIVC 使用检查表

- 预训练与测试数据是否来自同一图谱或供体？
- 基因 ID 是否使用相同版本，重复符号如何处理？
- 测试扰动靶基因是否在表达矩阵和模型词表中？
- 控制组是否匹配批次、时间和载体？
- 任务预测的是均值、完整分布还是差异表达集合？

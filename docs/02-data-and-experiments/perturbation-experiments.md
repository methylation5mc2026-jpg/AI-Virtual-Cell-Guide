# 扰动实验

## 基因扰动

- **knockout（敲除）**改变编码序列，效应可能不直接体现在目标 mRNA 数量上；
- **CRISPRi（干扰）**抑制转录，通常可从 RNA 读数看到目标下降；
- **CRISPRa（激活）**提高目标基因转录；
- **过表达**引入额外表达，但剂量和载体效应需要控制。

Perturb-seq 将 pooled CRISPR 筛选与单细胞 RNA 测序结合。每个细胞需要可靠关联到 guide，常见问题包括多 guide、未检出 guide、脱靶和弱扰动。

## 化学扰动

药物响应依赖剂量、暴露时间、细胞背景、溶剂和培养条件。同一化合物不能只用一个 ID 表示而忽略剂量和时间。组合药物还需要区分加性、协同和拮抗。

## 细胞因子与环境

细胞因子、缺氧、营养、基质和机械刺激影响细胞状态，但实验条件的可复现性可能低于基因扰动。模型条目应把环境上下文写入条件，而不是合并成一个标签。

## 设计一个可预测任务

最小任务应包含：

```text
输入 = 初始细胞背景 + 控制状态 + 干预表示 + 剂量 + 时间
输出 = 指定模态下的干预后细胞状态或状态分布
```

训练和测试必须说明：

- 测试扰动是否在训练中出现；
- 测试细胞类型、供体或组织是否出现；
- 是否有同批次控制；
- 输出是单细胞分布、pseudobulk 均值还是差异表达；
- 目标干预在训练数据中是否存在近邻或同通路基因。

## Arc 2025 数据设计案例

[Arc Virtual Cell Challenge](https://arcinstitute.org/news/behind-the-data-virtual-cell-challenge)使用 H1 人胚胎干细胞、双 guide CRISPRi 和高深度 10x Flex 测量约 300 个目标基因。训练、验证和测试按扰动目标拆分，并以 DES、PDS、MAE 评价不同用途。

它说明了两个重要原则：

1. 评测数据需要为泛化问题专门设计，而不是从训练数据随机抽细胞；
2. 高质量测量和清晰对照与模型架构同样重要。

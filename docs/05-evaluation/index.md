# 评测原则

## 评测对象不是一个分数

AIVC 至少需要同时评价：

- 全局表达是否接近；
- 真正响应的基因是否恢复；
- 不同扰动是否保持可区分；
- 细胞异质性和亚群是否保留；
- 在新背景中是否泛化；
- 不确定性是否与错误相关；
- 是否帮助选择更好的真实实验。

## 最低基线集合

所有扰动预测工作至少报告：

1. 控制均值；
2. 训练扰动平均效应；
3. 线性或岭回归；
4. 与复杂模型参数量无关的轻量 MLP；
5. 适用时的最近邻或通路基线。

## Arc 三指标

- **MAE**衡量全基因绝对误差，容易受大量不变基因主导；
- **DES**衡量预测与真实差异基因集合的恢复；
- **PDS**衡量预测能否正确区分不同扰动。

三者反映不同用途，不能相互替代。Arc 2025 中几乎所有模型的 MAE 都难以超过平均状态基线，说明单一全局误差不足以衡量生物学价值。

## 统计不确定性

- 按生物重复而不是细胞计算置信区间；
- 对模型比较做 bootstrap 时保持样本层级；
- 报告多个随机种子和超参数选择过程；
- 预注册或固定测试集，避免反复观察后调参；
- 明确异常值、失败运行和排除标准。

## 生物学验证层次

1. 同数据集 held-out；
2. 独立批次；
3. 独立实验室或平台；
4. 新细胞背景或供体；
5. 新模态或功能读数；
6. 前瞻性实验。

证据等级应随验证层次提高，而不是随模型参数量提高。

## 结果报告模板

- 数据版本与纳入标准；
- 训练/验证/测试拆分；
- 预处理在哪个集合拟合；
- 基线、模型预算和随机种子；
- 指标定义与实现版本；
- 失败扰动和亚组结果；
- 许可证、代码、配置和环境；
- 结论允许和不允许外推到哪里。

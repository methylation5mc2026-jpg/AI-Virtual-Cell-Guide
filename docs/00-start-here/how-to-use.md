# 如何使用本指南

本指南同时服务“系统学习”和“快速查阅”，不要求所有人从第一页线性读到最后。

## 四种使用方式

### 建立全局认知

按“从这里开始 → 基础 → 数据 → 模型 → 任务 → 评测”的顺序阅读。第一遍只需要能解释每层的输入、输出和证据边界。

### 针对问题查阅

从任务章节进入，例如“预测基因敲低后的表达变化”，再沿链接反查所需数据、模型和评测。不要先选模型再寻找问题。

### 复现一个闭环

扰动响应实践默认使用合成数据保证随时可运行，并提供 Norman 数据入口。它强调拆分、基线和误差分析，而不是追求排行榜结果。

### 跟踪领域进展

结构化目录按任务、模态和推荐等级生成。先阅读 `core` 条目，再用 `recommended` 和 `reference` 扩展。每个条目都记录复现状态和核验日期。

## 阅读符号

- **必读 / core**：支撑项目主线的定义、数据或方法。
- **推荐 / recommended**：对某一方向有代表性且资料相对完整。
- **参考 / reference**：适合专题调研，不要求入门阶段掌握。
- **预印本**：尚未完成同行评审，结论需要更谨慎地表述。
- **闭源或受限**：公开信息不足以独立复现结果。

## 每次阅读一个模型时

至少记下六件事：训练数据、输入表示、训练目标、下游任务、数据拆分、相对基线。参数量和模型名称放在最后。

## 每次新增一条资源时

只编辑 `catalog/*.yml`。目录页面由生成器创建，避免出现正文和资源表两份互相冲突的信息。

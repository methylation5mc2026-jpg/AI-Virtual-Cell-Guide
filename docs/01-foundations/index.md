# 生物学基础

## 从 DNA 到可观测表型

DNA 保存序列信息；转录生成 RNA；翻译生成蛋白。但“DNA → RNA → 蛋白”不是单向、静态流水线。染色质可及性、转录因子、RNA 加工、蛋白修饰、降解、代谢和细胞环境共同决定细胞状态。

对 AIVC 最重要的直觉是：**RNA 表达只是细胞状态的一个投影**。相似的 RNA 向量可能对应不同蛋白活性、空间位置或历史状态。

## 基因表达与调控

- **基因（gene）**：可产生功能性 RNA 或蛋白的遗传单位。
- **转录因子（transcription factor）**：调节基因转录的蛋白。
- **增强子与启动子**：影响转录发生位置和强度的调控区域。
- **基因调控网络（GRN）**：基因、调控因子和相互作用构成的网络。
- **通路（pathway）**：共同参与特定过程的一组分子反应。

模型学到的注意力或相关性不能自动解释为调控边。GRN 推断需要独立证据、扰动方向和适当的阴性对照。

## 细胞身份、状态与上下文

- **细胞类型**通常指相对稳定的身份，例如 T 细胞或成纤维细胞。
- **细胞状态**描述激活、应激、分化、疾病等更动态的变化。
- **上下文**包括物种、组织、供体、年龄、性别、疾病、培养条件和测量平台。

在数据中，这三者常被混合。模型如果仅利用批次或组织标签，也可能得到看似优良的细胞分类结果。

## 扰动

扰动是对系统施加的可控变化：

- 基因敲除、敲低、激活或过表达；
- 单药、组合药物和不同剂量；
- 细胞因子、营养、缺氧和机械环境；
- 时间、疾病或分化过程中的自然变化。

扰动响应可以是 RNA、蛋白、形态、存活、定位或功能读数。一个“虚拟细胞”至少应明确自己预测哪类干预下的哪一种读数。

## 群体与单细胞分布

细胞群体具有异质性。只预测平均表达会丢失：

- 亚群比例变化；
- 多峰响应；
- 罕见但重要的状态；
- 扰动后方差和协方差的变化。

但单细胞并不等于独立生物重复。来自同一培养皿、同一供体或同一测序批次的上千个细胞仍可能只有一个实验重复。

## 因果直觉

观测数据回答“哪些变量共同变化”；扰动数据更接近“改变 X 是否导致 Y”。即使有扰动，脱靶效应、选择偏差、技术噪声和未测量变量仍会影响因果解释。

!!! tip "最低掌握标准"
    进入模型章节前，应能解释基因表达、细胞类型与状态、扰动与对照、生物重复和技术重复、相关与因果的区别。
